# DSCP-SOT (Source of Truth)

Design tokens repository for the DSCP Design System.

## Structure

```
tokens.json    # All design tokens (colors, spacing, typography, etc.)
```

## Usage

This repository is consumed by the [DSCP](https://github.com/tiresomefanatic/DSCP) web application via GitHub API.

### Making Changes

1. Create a new branch
2. Edit tokens via the DSCP Token Editor UI
3. Create a Pull Request
4. Review and merge

## Token Format

Tokens follow the Design Tokens Community Group (W3C) format.
